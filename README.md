# One Piece: New World — Фаза 1 (версия 0.2.0)

Фанатский RPG-мод для **Minecraft 1.21.1 / NeoForge 21.1 / Java 21**.
Mod ID: `onepiece_newworld`. Зависимость: **GeckoLib 4.9.2** (понадобится для моделей с Фазы 2).

## Запуск

1. Установите **JDK 21** и **IntelliJ IDEA**.
2. Распакуйте архив, в IDEA: *File → Open* → папка `OnePieceNewWorld`.
3. Дождитесь импорта Gradle (первый раз 5–15 минут).
4. Вкладка **Gradle** справа → `Tasks` → `mod development` → **runClient**
   (или в терминале IDEA: `.\gradlew.bat runClient` на Windows, `./gradlew runClient` на Linux/macOS).
5. Готовый файл мода: `gradlew build` → `build/libs/onepiece_newworld-0.2.0.jar`.
   Для обычного Minecraft рядом с ним в папку `mods` нужно положить GeckoLib для NeoForge 1.21.1.

Если сборка или запуск падает, пришлите последние ~50 строк лога из окна *Build* или *Run*.

## Что сделано в Фазе 1

| Система | Что работает |
|---|---|
| Проект | Gradle (ModDevGradle), NeoForge 21.1, подключённая GeckoLib, серверный конфиг баланса |
| Реестры | Собственные реестры **способностей** и **дьявольских фруктов**: новый фрукт = подкласс + 3 строки регистрации |
| Данные игрока | Фрукт, энергия, уровень и опыт, мастерство фруктов, опыт трёх видов Хаки, путь (пират/дозорный), награда, заслуги, перезарядки. Сохраняются в мир и переживают смерть |
| Сеть | Клиент шлёт только «какая клавиша нажата». Урон, энергию, перезарядки и выбор пути проверяет сервер |
| Фрукты | Гому Гому (Парамеция), Мера Мера и Хиэ Хиэ (Логия), по 3 способности, пассивки, слабость в воде |
| Хаки | Наблюдение (импульс + уклонения) и Вооружение (бонус урона, пробивает Логию). Королевское уже хранится в данных, механика — в Фазе 3 |
| Прогрессия | Уровни 1–100 (+энергия, +сердце каждые 5 уровней), мастерство фрукта (+сила, −перезарядка) |
| Путь | Пират: награда за голову, объявления «РАЗЫСКИВАЕТСЯ», отряды Дозора на отметках награды. Дозорный: заслуги и 10 званий |
| Сущности | Снаряд стихии, **пират-головорез** (появляется на пляжах), **новобранец Дозора** (охотится на разыскиваемых пиратов) |
| Мир | Руда кайросеки под океанами, фрукты в сундуках структур |
| Интерфейс | Панель слева (уровень, энергия, способности с перезарядкой, Хаки, награда/звание) и **экран персонажа** (клавиша K) |

### Клавиши (меняются в *Настройки → Управление*)

| Клавиша | Действие |
|---|---|
| Z / X / C | Способности фрукта 1–3 |
| V | Хаки Вооружения вкл/выкл |
| G | Импульс Хаки Наблюдения |
| K | Экран персонажа, выбор пути |

## План ручной проверки

Собрать и запустить мод в среде разработки Claude было нельзя: серверы Minecraft и NeoForge оттуда закрыты.
Код сверен с исходниками NeoForge 1.21.1, но **в игре он ещё не проверялся**. Пройдите этот список
в творческом мире с читами и отметьте, что не работает.

1. `K` → экран персонажа открывается, видны кнопки выбора пути. Нажмите «Стать пиратом» — кнопки исчезают.
2. `/onepiece fruit @s mera` → слева появилась панель. Перейдите в режим выживания: `/gamemode survival`.
3. Z — огненный снаряд летит и взрывается. X — огненный луч. C — кольцо огня. Идёт перезарядка, тратится энергия.
4. Встаньте в огонь или лаву — урона нет. Зайдите в воду — игрок тонет, панель пишет «(подавлен)».
5. `/onepiece fruit @s hie` → идите по воде: она замерзает. Z, X, C — ледяные атаки.
6. `/onepiece haki @s armament 700`, `/onepiece haki @s observation 300` → V включает Вооружение (энергия убывает), G подсвечивает мобов.
7. Призовите пирата-головореза (яйцо во вкладке мода) — он атакует. Убейте его — растут опыт и награда.
8. `/onepiece bounty @s 9999999`, затем убейте моба → объявление «РАЗЫСКИВАЕТСЯ» и отряд Дозора рядом.
9. `/onepiece faction @s marine`, `/onepiece bounty @s 0` → новобранцы больше не нападают; убийство пирата даёт заслуги.
10. Перезайдите в мир → фрукт, уровень, Хаки и награда сохранились. Умрите → всё на месте, энергия полная.

Остальные команды: `/onepiece info`, `level`, `mastery`, `merit`, `cooldowns`, `patrol`.

## Архитектура

```
com/onepiece/newworld/
  OnePieceNewWorld.java   точка входа: только подключает модули
  core/          реестры предметов, блоков, эффектов, данных; конфиг; команды; тик игрока
  abilities/     Ability (общий класс), реестр, AbilityService (серверная проверка), Targeting
  fruits/        DevilFruit, реестр фруктов, предмет фрукта, правила подавления
    gomu/ mera/ hie/   фрукт + его способности
  haki/          виды Хаки и их логика
  combat/        правила урона (Логия, Вооружение, кайросеки, уклонение)
  progression/   PlayerData, уровни, путь, награды, заслуги
  entities/      сущности и их ИИ
  weapons/       оружие и снаряжение (пока — кайросеки)
  world/         лут фруктов в сундуках (генерация руды — в data/)
  networking/    пакеты и синхронизация
  client/        клавиши, панель, экран персонажа, рендеры
```

Пакеты `characters`, `bosses`, `islands`, `ships`, `effects` из ТЗ появятся в своих фазах:
пустых классов-заглушек в проекте нет.

Настройки баланса (энергия, урон, перезарядки, опыт, шанс фруктов, отряды Дозора) лежат в
`saves/<мир>/serverconfig/onepiece_newworld-server.toml` после первого запуска мира.

### Как добавить новый фрукт

1. Создайте `fruits/<имя>/<Имя>Fruit.java` (подкласс `DevilFruit`) и `<Имя>Abilities.java`.
2. Зарегистрируйте способности в `abilities/ModAbilities.java`, фрукт — в `fruits/ModFruits.java`, предмет — в `core/ModItems.java`.
3. Добавьте текстуру `textures/item/<имя>_fruit.png`, модель предмета и строки в `lang/ru_ru.json` и `en_us.json`.

## Важно про контент из аниме

В моде используются названия фруктов и техник, но **нет рисунков персонажей, символики команд
и узнаваемых дизайнов мечей**. Все текстуры в 0.2 — собственные заготовки. Модели и скины персонажей
(Фаза 5) и легендарных мечей нужно рисовать самостоятельно или заказывать у художников.
