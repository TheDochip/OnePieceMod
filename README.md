# One Piece: New World — Фаза 3 (версия 0.4.0)

Фанатский RPG-мод для **Minecraft 1.21.1 / NeoForge 21.1 / Java 21**.
Mod ID: `onepiece_newworld`. Зависимости: **GeckoLib 4.9.2** (модели боссов и NPC) и
**Player Animation Library 1.1.6** (анимации тела игрока). В режиме разработки обе подключаются сами.

## Запуск

1. Установите **JDK 21** и **IntelliJ IDEA**.
2. Распакуйте архив, в IDEA: *File → Open* → папка `OnePieceNewWorld`.
3. Дождитесь импорта Gradle (первый раз 5–15 минут).
4. Вкладка **Gradle** справа → `Tasks` → `mod development` → **runClient**
   (или в терминале IDEA: `.\gradlew.bat runClient` на Windows, `./gradlew runClient` на Linux/macOS).
5. Готовый файл мода: `gradlew build` → `build/libs/onepiece_newworld-0.4.0.jar`.
   Для обычного Minecraft рядом с ним в папку `mods` нужно положить GeckoLib и Player Animation Library для NeoForge 1.21.1.

Если сборка или запуск падает, пришлите последние ~50 строк лога из окна *Build* или *Run*.

| Сеть | Клиент шлёт только «какая клавиша нажата». Урон, энергию, перезарядки и выбор пути проверяет сервер |

| Прогрессия | Уровни 1–100 (+энергия, +сердце каждые 5 уровней), мастерство фрукта (+сила, −перезарядка) |
| Путь | Пират: награда за голову, объявления «РАЗЫСКИВАЕТСЯ», отряды Дозора на отметках награды. Дозорный: заслуги и 10 званий |
| Сущности | Снаряд стихии, **пират-головорез** (появляется на пляжах), **новобранец Дозора** (охотится на разыскиваемых пиратов) |
| Мир | Руда кайросеки под океанами, фрукты в сундуках структур |
| Интерфейс | Панель слева (уровень, энергия, способности с перезарядкой, Хаки, награда/звание) и **экран персонажа** (клавиша K) |

## Что сделано в Фазе 2 — боевая система

| Система | Что работает |
|---|---|
| Стили | **Кулаки** (пустая рука), **катана** (меч в руке), **три меча** (мечи в обеих руках + третий на панели). Любой ванильный меч тоже подходит |
| Цепочки | ЛКМ — серия ударов (кулаки 4, мечи 3), последний — добивающий с оглушением; Shift + ЛКМ — тяжёлый удар (у кулаков апперкот-подброс); удар в прыжке; жонглирование врагом в воздухе; казнь ×2 по врагу с <15% здоровья |
| Защита | Зажатая ПКМ — блок спереди (меч пропускает 30% урона, кулаки 50%, тратит энергию, без энергии блок пробивается). ПКМ в момент удара — **парирование**: урона нет, враг оглушён на 1.5 с, следующий удар ×1.5 |
| Уклонение | Left Alt — рывок в сторону движения, 8 тиков неуязвимости, 15 энергии; в воздухе — один рывок до приземления |
| Летящие удары | С мечом в руке Z / X / C — горизонтальный, вертикальный и «буря клинков» (с тремя мечами — огромный удар). Удары **режут блоки**: сила разреза 1–5 = разряд меча + мастерство + Вооружение. Бедрок, сундуки и кайросеки не режутся. С включённым Вооружением удар чёрный |
| Мечи | Катана, вазамоно, о-вазамоно (разряды 1–3, рецепты в книге рецептов) |
| Мастерство | Растёт за попадания, парирования и техники: +6% урона за ступень, сильнее разрез, короче перезарядка техник |
| Разрушение | Конфиг `destruction`: `OFF` / `PERMANENT` (по умолчанию) / `RESTORE` (блоки возвращаются через 120 с), лимит 300 блоков за тик, защита спавна и приватов |
| Анимации | Через Player Animation Library: как только файл анимации появится в `assets/onepiece_newworld/player_animations/`, она заиграет; пока анимации нет — обычный взмах рукой |
| Интерфейс | Счётчик комбо у прицела, стиль и ступень мастерства на панели, техники меча вместо способностей фрукта, пока в руке меч |

## Что сделано в Фазе 3 — Хаки

| Система | Что работает |
|---|---|
| Сила воли | Уровень + 20 × Королевское + 5 × Вооружение; у мобов — здоровье / 2. Сравнивается во всех столкновениях воли |
| Королевское Хаки | Выпадает с шансом 1% при первом входе в мир (конфиг `haki.conquerorChance`) или командой. Спит, пока в бою здоровье не упадёт ниже 20%, — тогда просыпается с волной |
| Волна (H) | Радиус 8 + 4 × уровень, 40 энергии, 30 с. Кто слабее вас вдвое — без сознания на 5–10 с; с ур. 2 устоявших давит замедлением и слабостью; с ур. 3 подавляет силы фрукта на 3–12 с |
| Покрытие (ур. 4) | С включённым Вооружением: удары +25% урона и на 2 блока дальше, пробивают блок тех, чья воля слабее; расход Вооружения ×2 |
| Ур. 5 | С Вооружением каждый приём оглушает цель на 1 с |
| Столкновение | Двое с Королевским 4+ бьют друг друга покрытыми ударами (или волна задевает равного) — оба замирают, чёрно-красные молнии, ударная волна, трещины в земле на 30 с, тряска камеры; более сильная воля отбрасывает и оглушает соперника |
| Вооружение | Закалка: включённое Вооружение снижает входящий урон на 5% за уровень (до 25%), Вооружение нападающего снимает эту защиту |

### Клавиши (меняются в *Настройки → Управление*)

| Клавиша | Действие |
|---|---|
| ЛКМ / Shift + ЛКМ | Удар цепочки / тяжёлый удар (кулаки или меч) |
| ПКМ (зажать) | Блок; нажать в момент удара — парирование |
| Left Alt | Уклонение |
| H | Волна Королевского Хаки (только у тех, кому оно дано) |
| Z / X / C | С мечом — летящие удары; без меча или с Shift — способности фрукта 1–3 |
| V | Хаки Вооружения вкл/выкл |
| G | Импульс Хаки Наблюдения |
| K | Экран персонажа, выбор пути |

## Автоматические проверки

При каждом изменении кода GitHub Actions (вкладка **Actions** репозитория):
1. компилирует мод (`gradlew build`) и выкладывает готовый `.jar` в раздел *Artifacts* сборки;
2. запускает игровой сервер с модом и автотестами (`gradlew runGameTestServer`, класс `gametest/CoreGameTests`).

Автотесты проверяют: реестры фруктов и способностей, сохранение и загрузку данных игрока,
иммунитеты Гому и Мера, неуязвимость Логии и пробитие кайросеки, подавление сил кайросеки,
снаряжение NPC и выбор целей Дозором, попадание и поджог огненного снаряда.
Тесты боя (`gametest/CombatGameTests`): выбор стиля по рукам, цепочка ударов и её восстановление,
парирование с оглушением, блок только спереди, неуязвимость уклонения и его перезарядка,
летящий удар режет камень, но не бедрок, слабый удар гаснет о камень, сила разреза, сохранение мастерства.
Тесты Хаки (`gametest/HakiGameTests`): формула воли, однократный розыгрыш и пробуждение Королевского,
волна (без сознания / давление / сильный устоял), подавление фрукта, покрытие пробивает блок, итог столкновения.
Запуск сервера заодно проверяет, что все рецепты, лут, теги и генерация мира загружаются без ошибок.

## План ручной проверки

Сервер в автотестах работает без графики, поэтому интерфейс, клавиши, частицы и модели NPC
нужно проверить в обычной игре (`runClient`):

1. `K` → экран персонажа открывается, видны кнопки выбора пути. Нажмите «Стать пиратом» — кнопки исчезают.
2. `/onepiece fruit @s mera` → слева появилась панель. Перейдите в режим выживания: `/gamemode survival`.
3. Z — огненный снаряд летит и взрывается. X — огненный луч. C — кольцо огня. Идёт перезарядка, тратится энергия.
4. Встаньте в огонь или лаву — урона нет. Зайдите в воду — игрок тонет, панель пишет «(подавлен)».
5. `/onepiece fruit @s hie` → идите по воде: она замерзает. Z, X, C — ледяные атаки.
6. `/onepiece haki @s armament 700`, `/onepiece haki @s observation 300` → V включает Вооружение (энергия убывает), G подсвечивает мобов.
7. Призовите пирата-головореза (яйцо во вкладке мода) — он атакует. Убейте его — растут опыт и награда.
8. `/onepiece bounty @s 9999999`, затем убейте моба → объявление «РАЗЫСКИВАЕТСЯ» и отряд Дозора рядом.
9. `/onepiece faction @s marine`, `/onepiece bounty @s 0` → новобранцы больше не нападают; убийство пирата даёт заслуги.
10. Перезайдите в мир → фрукт, уровень, Хаки и награда сохранились. Умрите → всё на месте, энергия полная.

Бой (Фаза 2):

11. `/give @s onepiece_newworld:katana`, призовите пирата-головореза. ЛКМ по нему — три удара подряд, у прицела «x3 КОМБО», последний отбрасывает.
12. Зажмите ПКМ, когда пират бьёт: урон меньше, энергия тратится. Нажмите ПКМ прямо в момент удара — «Парирование!», пират замирает.
13. Left Alt с зажатой A/D — рывок вбок. Прыгните и нажмите Left Alt ещё раз — рывок в воздухе.
14. Встаньте перед каменной стеной: Z — горизонтальный разрез прорезает полосу; X — вертикальный. Обычная катана режет землю и дерево, но не камень:
    `/onepiece weapon @s katana 1500` или `/give @s onepiece_newworld:o_wazamono_katana` — теперь режет камень. `/onepiece haki @s armament 750` + V — удар чёрный и режет ещё твёрже.
15. Возьмите катану во вторую руку и ещё один меч на панель — стиль «Три меча», C — огромный удар.
16. Пустая рука: ЛКМ — 4 удара кулаками, Shift + ЛКМ — апперкот подбрасывает моба, прыгайте и бейте его в воздухе.

Хаки (Фаза 3):

17. `/onepiece conqueror @s give`, `/gamemode survival`, дайте мобам побить вас до 2 сердец → «Пробуждено Королевское Хаки!», волна, мобы рядом замирают.
18. `/onepiece haki @s conqueror 1500` → H: красно-чёрное кольцо расходится, камера трясётся, слабые мобы без сознания (стоят, не бьют), голем замедлен.
19. `/onepiece haki @s armament 300`, V → удары кулаком/мечом достают дальше и сильнее (покрытие), энергия убывает быстрее.
20. Вдвоём по сети: у обоих `/onepiece haki <ник> conqueror 1500` и V, ударьте друг друга в течение секунды → столкновение с молниями и трещинами.

Остальные команды: `/onepiece info`, `level`, `mastery`, `weapon`, `conqueror <игрок> give|awaken|remove`, `merit`, `cooldowns`, `patrol`.

## Архитектура

```
com/onepiece/newworld/
  OnePieceNewWorld.java   точка входа: только подключает модули
  core/          реестры предметов, блоков, эффектов, данных; конфиг; команды; тик игрока
  abilities/     Ability (общий класс), реестр, AbilityService (серверная проверка), Targeting
  fruits/        DevilFruit, реестр фруктов, предмет фрукта, правила подавления
    gomu/ mera/ hie/   фрукт + его способности
  haki/          Наблюдение и Вооружение (HakiService), Королевское (ConquerorService), сила воли
  combat/        правила урона, стили и цепочки ударов (CombatService), блок/парирование/уклонение
                 (DefenseRules), техники меча, сила разреза
  progression/   PlayerData, уровни, путь, награды, заслуги
  entities/      сущности и их ИИ
  weapons/       катаны трёх разрядов, снаряжение из кайросеки
  world/         лут фруктов, разрушение блоков (DestructionManager) и их возврат (DestructionData)
  networking/    пакеты и синхронизация
  client/        клавиши, ввод боя, панель, экран персонажа, рендеры, мост к Player Animation Library
tools/           скрипты, которые генерируют переводы (lang.py) и текстуры (tex.py, tex_combat.py)
```

Пакеты `characters`, `bosses`, `islands`, `ships`, `effects` из ТЗ появятся в своих фазах:
пустых классов-заглушек в проекте нет.

Настройки баланса (энергия, урон, перезарядки, опыт, шанс фруктов, отряды Дозора) лежат в
`saves/<мир>/serverconfig/onepiece_newworld-server.toml` после первого запуска мира.

### Как добавить новый фрукт

1. Создайте `fruits/<имя>/<Имя>Fruit.java` (подкласс `DevilFruit`) и `<Имя>Abilities.java`.
2. Зарегистрируйте способности в `abilities/ModAbilities.java`, фрукт — в `fruits/ModFruits.java`, предмет — в `core/ModItems.java`.
3. Добавьте текстуру `textures/item/<имя>_fruit.png`, модель предмета и строки в `lang/ru_ru.json` и `en_us.json`.

## Важно про контент из аниме

В моде используются названия фруктов и техник, но **нет рисунков персонажей, символики команд
и узнаваемых дизайнов мечей**. Все текстуры в 0.2 — собственные заготовки. Модели и скины персонажей
(Фаза 5) и легендарных мечей нужно рисовать самостоятельно или заказывать у художников.
